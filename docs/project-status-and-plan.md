# TeachCut 项目状态与近期开发计划

更新日期：2026-07-12

## 项目定位

TeachCut 当前是以 OpenShot 为基础、面向 Windows 11 的长期维护分支。现阶段工作重点不是重写完整编辑器，而是在保留 OpenShot 成熟剪辑能力的前提下，建立可重复的 Windows 构建、现代化 Qt 界面、NVIDIA 硬件导出和 D3D11 低开销预览链路。

项目已经从“能够在 Windows 上构建和打包”进入“将 GPU 实验能力接入真实编辑流程”的阶段，但尚未达到面向普通用户默认启用 GPU 预览的成熟度。

## 当前状态

### 已完成

- `develop` 是当前唯一日常开发分支，并与 `origin/develop` 保持同步。
- Windows Qt 5 和 Qt 6 使用独立的原生构建、安装与冻结目录。
- `libopenshot` 与 `libopenshot-audio` 已纳入 `native`，应用和原生引擎可以在同一次提交中修改和回滚。
- Windows 构建脚本能够完成原生库编译、Python 测试、cx_Freeze 冻结和 GUI 启动冒烟验证。
- TeachCut Modern 主题、Qt 6、高 DPI 和混合 SVG/PNG 图标加载规则已经落地。
- H.264、HEVC 和 AV1 NVENC 导出链路已经建立，并完成 RTX 4090 4K 合成素材基准。
- D3D11 共享设备、GPU Frame、按需回读和 Qt 原生窗口直显的独立验证已经完成。

### 2026-07-12 验证基线

- Python 测试：417 项通过。
- D3D11 零拷贝基础验证：60/60 帧保留在 GPU，0 次常规 GPU 到 CPU 下载，约 166 fps。
- D3D11 原生直显验证：60/60 帧直显，0 次 Python/QImage 回退，0 次呈现失败，约 112 fps。
- 工作区干净，`develop` 与 `origin/develop` 无领先或落后提交。

这些数字用于证明当前底座工作正常，不能直接视为完整时间线或最终软件的性能数据。

## 当前主要边界

- 零拷贝和直显目前只覆盖独立 `FFmpegReader`，正常 Timeline 仍创建 CPU Frame 并执行图层合成。
- `FFmpegReader` 当前只在没有 Parent Clip 时保留 D3D11 纹理，因此素材进入 Clip/Timeline 后会退出实验路径。
- GPU 实验开关默认关闭，尚未提供面向普通用户的设置入口。
- GPU 验证脚本尚未进入 GitHub Windows CI；原生库构建当前也没有运行其完整 C++ 测试套件。
- 性能测试以合成 H.264 素材为主，缺少课程录像、手机 VFR、10-bit HEVC 等真实素材回归。
- 当前最新可分发 ZIP 早于 UI 现代化和 D3D11 直显提交，需要在本周重新生成。
- 仓库是浅克隆，目前只有 `origin`，还没有明确的 OpenShot 上游同步和冲突处理流程。
- `windows-build-lock.json` 记录了已验证工具版本，但 MSYS2 包列表没有锁定精确包版本，仍存在依赖漂移风险。

## 今日计划：阶段 2.5 单素材时间线直显

今日目标是在开发者实验开关下跑通最简单的真实 Timeline GPU 路径，并保持所有复杂场景的确定性 CPU 回退。今天不默认开放 GPU 预览。

### 1. 建立严格的 GPU 直通资格判断

首版只允许以下场景：

- Windows + Qt 6；
- D3D11 硬件解码成功；
- 当前帧只有一个可见视频 Clip；
- 没有重叠图层、视频特效、透明度动画、旋转、裁剪、剪切或变速；
- `ENABLE_D3D11_ZERO_COPY` 与 `ENABLE_D3D11_DIRECT_PRESENT` 同时启用。

任何条件不满足时必须继续使用现有 CPU/QImage 路径。

### 2. 建立 Timeline GPU 快速路径

在满足资格条件时，让 Timeline 返回带有 `GpuFrameSurface` 的 Frame，跳过黑色 CPU Frame 和 QImage 图层合成。音频、时间位置、暂停与 Seek 语义必须保持不变。

### 3. 建立确定性回退

加入第二个素材、特效或变换后，当前帧必须自动回到 CPU 路径，不能出现黑屏、丢音频、错误缓存或 GPU/CPU 帧混用。

### 4. 增加专项验证

计划新增 `scripts/verify-d3d11-timeline.ps1` 和对应 Python 验证脚本，至少覆盖：

- 单素材连续播放 300 帧；
- `gpu_downloads == 0`；
- `direct_presents > 0`；
- `present_failures == 0`；
- 加入特效或重叠素材后发生预期 CPU 回退；
- 暂停、逐帧、Seek 和窗口缩放可用。

### 5. 今日完成标准

- 417 项 Python 测试继续通过；
- 原有零拷贝基础与 D3D11 直显验证继续通过；
- 新增单素材 Timeline 专项验证通过；
- Qt 6 构建、冻结和启动冒烟通过；
- 更新相关性能文档；
- 在 `develop` 上形成一个可独立回滚的完整提交。

如果不能完整满足这些条件，实验开关继续默认关闭，不留下半启用状态。

## 本周不做

- GPU 多轨合成；
- GPU 特效链；
- 编码器纹理直送；
- 大规模 UI 重设计；
- 将实验性 GPU 预览默认打开。

本周的核心交付是：让单素材预览形成可测量、可回退、可打包的完整闭环。

## 文档目录边界

- `doc/`：OpenShot 上游的 Sphinx/reStructuredText 用户手册源文件，主要用于生成英文及多语言网站、HTML 和 PDF 手册。
- `docs/`：TeachCut 分支自己的工程说明、性能记录、设计边界和开发计划。
- `scripts/README-windows.md`：Windows 构建、测试、打包和 GPU 验证的操作手册。

TeachCut 的开发计划和阶段报告默认写入 `docs/`，避免与上游用户手册混在一起。
